
# Language support for Embedded SQL

This VS Code extension provides basic syntax highlighting and snippets for Embedded SQL in C (ECPG, Pro*C).

## Features

- Syntax highlighting for `ecpg` and `proc` embedded-SQL sources.
- File associations: `.pgc` -> `ecpg`, `.pc` -> `proc`.
- Handy snippets for common `EXEC SQL` constructs.

## Included snippets (prefix)

- sql statements (`EXEC SQL`)

## Installation

- Install the VSIX manually.

## Usage

- Open or create files with a `.pgc` or `.pc` extension to get syntax highlighting.
- Trigger snippets via their prefixes or use the `Insert Snippet` command.
